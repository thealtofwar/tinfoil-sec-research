All PoCs are local only. The browser PoCs intercept every request with Playwright
route handlers (no socket is ever opened to tinfoil.sh or attacker.example) and
start Chromium with --host-resolver-rules=MAP * ~NOTFOUND so no hostname resolves.

Prerequisites already set up in this work dir:
  ../tinfoil-webapp-sandbox/node_modules   (npm ci; playwright + chromium-headless-shell 153)
  ../tinfoil-webapp/node_modules           (npm ci --ignore-scripts; vitest)
  ../syslibs/root/usr/lib/x86_64-linux-gnu  (4 Ubuntu libs chromium needs, extracted from .debs, no system install)
  node_modules -> ../tinfoil-webapp-sandbox/node_modules
